description: 启动 Sketch Agent 画板页，用数位板或鼠标画草图、打字，发给 Claude 多轮对话。用户要打开画板、手绘输入时使用。
disable-model-invocation: true
allowed-tools: Bash(node *)
---

```!
node "${CLAUDE_PLUGIN_ROOT}/scripts/launch.js" start --cwd "${CLAUDE_PROJECT_DIR}" --session "${CLAUDE_SESSION_ID}"
```

上面是启动结果。按下面做，不要做别的：

1. 用一两句话告诉用户画板地址。
2. 如果结果里有「接单命令」：用 Bash 工具、`run_in_background: true`、`timeout: 7200000`，**原样**运行那条命令，然后结束这一轮。这样画板发来的消息会直接交给这个 Code 会话回答，上下文和这个窗口是同一份。告诉用户：首次运行时如果弹出权限确认，选「始终允许」，之后画板消息才不会每次打断。
3. 之后每次这个后台命令结束，看它的输出：
   - 「【画板消息 …】」：先按里面说明读图（如有草图，用 Read 读图片路径），像用户直接在这个窗口里问你一样回答；回答完立刻按输出末尾的命令再次后台运行。
   - 「等了很久，画板没有新消息」：直接再次后台运行输出里的命令，不要输出别的话。
   - 「已停止或重启」或「已有另一个接单命令接管」：循环结束，不要再运行，只用一句话告诉用户。
4. 用户说要关掉画板，或运行了 /sketch-agent:stop，就不要再运行接单命令。

如果结果里没有「接单命令」（不在 Code 会话里启动），只告诉用户地址即可，画板会用独立 agent 回答。

如果结果显示启动失败，把日志里的报错要点告诉用户，并给出下一步建议。
